# Font data provenance

The `.lvfnt` blobs in this directory are generated by `cargo xtask fonts` from
the glyph tables in LVGL v9.6.0, commit `80ca777e37a2b176770726a02e07a6fb79ef0b39`,
files `src/font/lv_font_<name>.c`. Those C files were themselves produced by
[lv_font_conv](https://github.com/lvgl/lv_font_conv) with the options recorded
in each file's header, e.g. for `montserrat_14`:

```
--bpp 4 --size 14 --font Montserrat-Medium.ttf -r 0x20-0x7F,0xB0,0x2022
--font FontAwesome5-Solid+Brands+Regular.woff -r <symbol code points>
--format lvgl --force-fast-kern-format
```

`cargo xtask fonts --check` fails when a blob no longer matches the upstream
source, so the files are reproducible from the pinned upstream commit.
